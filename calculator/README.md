 About
  A beginner-friendly command-line calculator written in Python.
  It features a simple menu interface that allows users to perform basic arithmetic operation  repeatedly until they choose to exit.
 Features
   Displays a simple, numbered menu for operations.
   Performs addition, subtraction ,multiplication ,and division.
   Handles division by zero with an appropriate error message.
   Allows users to perform multiple calculations without restarting the script.
   Handles invalid menu choices gracefully.
  Technologies Used
    Python3
  Python Concepts Used
    While Loop: Keeps the calculator running continuously.
    Conditional Statements (if/elif/else):
    Handles menu choices and arithmetic operations.
    Membership Operator (in): Checks whether the users choice is valid.
    Type Casting :Converts string inputs into numbers using float()
    f-strings :Formats and displays calculation results.
    Break Statement: Exits the loop when the user chooses option 5.
   How to Run 
     Make sure Python 3 is installed on your system.
     Open your terminal or command prompt.
     Navigate to the project folder.
     Run the script using the following command Python menu_calculator .py
